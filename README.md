### 流量和带宽不是同一个概念

很多用户容易混淆：

* 带宽：决定瞬时传输能力
* 流量：决定一个周期内可使用的数据量

例如 10Gbps 峰值带宽并不意味着无限流量。

如果运行视频、下载、文件分发等业务，需要重点看流量限制。
